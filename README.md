# 月度成本结算平台

这是一个面向企业内部月结的 Web 应用，使用 Python、Django 和 PostgreSQL。

系统按照当前核算口径完成：

- 库存出入库、采购合同、采购发票、销售发票和生产订单导入
- 采购入库与合同、发票自动匹配，发票可以核销以前月份的入库
- 系统首期可导入期初存货余额，以及期初采购暂估和期初发出商品明细，由以后发票逐笔核销
- 采购入库按合同暂估价固定计价，后续发票不反写库存金额
- 本月采购暂估价差单独汇总供总账处理
- 月末采购暂估余额包含以前月份尚未到票的入库
- 销售发票可以核销本月或以前月份尚未开票的销售出库
- 月末已出库未开票按匹配数量拆分成本，并形成发出商品滚动勾稽
- 生产领退料与生产订单匹配
- 发票、生产订单及库存流水双向查看匹配关系
- 按表头字段筛选，点击具体单据进入手工匹配
- 单据和库存流水支持自动匹配、手工匹配、忽略匹配
- 月末加权平均价计算
- 按现行材料金额比例及工时规则分配车间费用
- 完工成本、在产品和生产入库成本计算
- “本月生产成本与费用”按全部车间或单一车间汇总材料、费用、完工成本、期末在制和闭合差额
- 上期锁账后自动承接库存、在产品、未完工订单和合同余额
- 各车间可独立结转，结转顺序由用户维护
- 上游生产入库成本完成后，下游领用按月末加权价计价
- 库存、订单、生产入库和销售成本自动勾稽
- 异常处理、期间锁定和 Excel 结果导出

## 快速运行

复制环境变量：

```text
copy .env.example .env
```

使用 Docker：

```text
docker compose up --build
```

首次启动后，访问 `http://localhost:8000`。默认管理员由环境变量
`DJANGO_SUPERUSER_USERNAME` 和 `DJANGO_SUPERUSER_PASSWORD` 创建。
容器内使用 Gunicorn 运行 Web 服务，并由 WhiteNoise 提供静态资源。

## 本地开发

```text
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
set DB_ENGINE=sqlite
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py seed_demo
.venv\Scripts\python manage.py runserver
```

生产环境默认连接 PostgreSQL；SQLite 只用于本地测试。

## 导入文件

`sample_templates` 目录提供十一类 CSV 模板，也支持上传 `.xlsx`：

- 库存出入库流水
- 采购合同
- 采购发票
- 销售发票
- 生产订单
- 车间费用
- 期初存货
- 期末存货
- 期初在产品
- 期初采购暂估明细（仅系统首期）
- 期初发出商品明细（仅系统首期）

系统支持常见中文列名别名，导入文件的表头可以在前 10 行内。

库存出入库流水模板按
创建时间、物料名称、物料编号、分类、物料规格、仓库名称、批号、操作数量、
主单位、辅助数量、辅助单位、备注、业务单据编号、业务类型、供应商名称、单价、
金额 提供（必填：创建时间、物料编号、操作数量、业务类型）。出入库方向按
业务类型自动判断；需要自动匹配合同、发票、生产订单时，可在模板后追加
可选列：供应商编码、合同号、工单号、车间、销售订单号、客户编码、客户名称、
发票号、方向。

系统首期的“期初存货”是启用日前的库存余额台账，作为独立余额进入月末
加权平均计价，不生成当月库存流水；以后月份由上一自然月锁账结果自动承接，
也可人工上传同物料数据覆盖。期初存货模板按
日期、物料号、物料名称、分类名称、仓库名称、批次号、结存数量、单位名称、
单价、金额、备注 提供（单价和金额至少填写一项）。
“期末存货”默认由系统结算时自动计算（期末＝期初＋本月入库－本月出库），
模板与期初存货同格式，可按需上传以覆盖个别物料的自动计算数，不参与库存流水。
系统首期的“期初采购暂估明细”是启用日前已经入库但尚未到票的余额；
“期初发出商品明细”是启用日前已经出库但尚未开票的余额。两类资料作为
独立台账保存，不伪造当月库存流水。以后月份无需重复导入，采购、销售发票
会继续核销剩余明细。启用日前仍在执行的采购合同，可按剩余数量作为首期
采购合同资料导入。

## 月结顺序

1. 新建月份并上传资料
2. 自动匹配采购、销售和生产订单
3. 在采购、销售、订单或流水匹配页面复核结果；必要时点击单据手工调整或忽略
4. 查看“月末暂估”和“暂估差异”，分别核对未到票余额及交总账处理的本月价差
5. 查看“月末未开票”，核对本月及以前月份形成的发出商品
6. 在“车间结转”中维护上游到下游的结转顺序
7. 逐个结转车间，或按用户顺序执行完整结算
8. 查看库存计价、订单成本、异常和勾稽结果
9. 导出结算工作簿
10. 勾稽通过后锁账

首个核算期间需要提供期初数据；有历史未到票、未开票时还需提供上述两本明细台账。
以后月份以上一自然月的锁账结果自动生成期初；
上期未锁账或月份断档时，本期不能正式结算。

当下游车间领用上游车间的半成品或产成品时，先结转上游车间。系统写入上游
生产入库成本后重新计算月末加权价，再结转下游车间。

完整业务规则、操作步骤和验收范围见 `交付说明.md`。

HOW IT IS CALCULATED

取数口径与说明

  • 凭证结构：一张凭证、一条分录流，不按车间分块、没有 ①②③ 小计； 借方科目合并——各车间合计成一行「生产成本—直接材料」； 贷方按车间顺序逐行列出各车间领用的物料大类（摘要「{月}月{车间}领用{物料大类}」）， 科目为 {{ voucher.accounts.raw }}—大类（原料、纤维）／{{ voucher.accounts.inhouse }}—大类（纱线、染色纤维、熟条、坯布、面料）。
  • 除浆粕车间外（染色、纺纱、包覆、针织、机织）：按工单投料台账取数。 台账行用「工单号 → 工单的生产部门」归车间，数量取台账的实际投料数量（已扣回撤）， 金额 ＝ 实际投料数量 × 该物料的月末加权平均价。 本期台账 {{ voucher.summary.ledger_rows }} 行 / {{ voucher.summary.ledger_amount|floatformat:2|thousands }}。
  • 浆粕车间（没有工单）：按库存流水「领料出库」取数，且备注里必须同时出现 「浆粕」与当期月份（如「浆粕车间7月领用」）才算浆粕车间的领料。 本期 {{ voucher.summary.pulp_rows }} 行 / {{ voucher.summary.pulp_amount|floatformat:2|thousands }}。
  • 无工单领料：没有工单、备注也不符浆粕认领规则的领料出库，按大类单列在 「无工单领料」（本期 {{ voucher.summary.unallocated_rows }} 行 / {{ voucher.summary.unallocated_amount|floatformat:2|thousands }}）里。 其中备注写了浆粕但月份不是当期（如「浆粕车间6月领用」）的有 {{ voucher.summary.mismatch_rows }} 行 / {{ voucher.summary.mismatch_amount|floatformat:2|thousands }}，需要你规范领料备注后才能归位。
  • 口径提醒：以工单投料台账为准后，个别「投料」流水在台账里没有对应记录（见生成前检查）， 这些不进入本凭证；金额可能与「勾稽异常」里「投料出库金额」的左值（库存出库口径）相差这一点。
  • 贷方科目：{{ voucher.accounts.raw }}＝外购（原料、纤维，入库来源为采购入库）； {{ voucher.accounts.inhouse }}＝上游车间产出（纱线、染色纤维、熟条、坯布、面料，入库来源为报工）。
  • 数量列：按原始单位相加，仅用于车间/仓库核对，不参与借贷平衡。

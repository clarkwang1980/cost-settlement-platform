HOW IT IS CALCULATED

取数口径与说明

  • 借方：库存商品—物料分类（{{ voucher.accounts.inventory }}）， 每个车间的每个物料分类一行，摘要「{月}月{车间}完工入库{物料分类}」。
  • 贷方：{{ voucher.accounts.elements|join:" / " }} （全车间汇总，各一行，摘要「{月}月各车间完工入库{要素}」）； 浆粕车间也并进这三个要素，不再单独挂一个车间科目。
  • 金额基准＝工单完工成本（＝报工数量 × 完工单位成本，与「工单成本」页一致）： 本期 {{ voucher.summary.order_count }} 张工单 / {{ voucher.summary.order_amount|floatformat:2|thousands }}。 贷方三个要素分别取工单成本的完工直接材料 / 完工人工 / 完工制造费用， 三者相加＝完工成本，所以借贷仍然相等。
  • 不用库存流水：报工入库流水里有重复行、也有漏传（见上方生成前检查）， 按流水入账会把成本重复计一遍，所以金额一律取工单完工成本；差异只在检查里列示。
  • 浆粕车间（没有工单、不走工单成本）：按库存流水「生产入库」单独归集 {{ voucher.summary.pulp_count }} 个成品 / {{ voucher.summary.pulp_amount|floatformat:2|thousands }}， 贷方拆直接材料 {{ voucher.summary.pulp_element_totals.直接材料|floatformat:2|thousands }} / 直接人工 {{ voucher.summary.pulp_element_totals.直接人工|floatformat:2|thousands }} / 制造费用 {{ voucher.summary.pulp_element_totals.制造费用|floatformat:2|thousands }} （直接材料＝浆粕原料领料、直接人工＝车间工资、制造费用＝其余车间费用），并入上面那三个要素行。
  • 数量列：按原始单位相加，仅用于车间/仓库核对，不参与借贷平衡； 贷方要素行的数量是各车间合计，跨车间不同单位不能直接比。
  • 未列入的工单：本期完工成本为 0 的工单（未完工或成本算不出） {{ voucher.summary.zero_cost_orders }} 张，没有列入本凭证。

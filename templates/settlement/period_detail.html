操作说明（怎么结账、锁账后怎么进、怎么解锁）
  1. 每月顺序：① 资料导入 → ② 采购发票匹配 → ③ 月末未开票 → ④ 工单报工 → ⑤ 车间费用（左侧「车间费用」页按车间、按月份直接录入，不用上传）→ ⑥ 车间结转 → ⑦ 按车间顺序完整结算（右上角按钮）→ ⑧ 库存结转 → ⑨ 勾稽异常 → ⑩ 锁账。
  2. 锁账：点右上角「勾稽通过，锁定本月」。只有同时满足——各车间结转完成、 结算成功且已收敛、无未处理阻断异常、无未确认勾稽差异——按钮才会出现； 不满足时表里会写「暂不能锁账：原因」。
  3. 锁账后：本期变只读——工单成本、期末库存、单价表、勾稽、损益表都能看、能导出； 但不能上传资料、重新匹配、重新结算、修改车间费用、处理异常。 怎么进本期：首页（期间列表）点本期，或用顶部期间导航，或直接打开本期链接。
  4. 解锁（重开）：期间详情页 → 锁账横幅旁的「管理员重开期间」（仅系统管理员可见）→ 状态回到「待处理」；注意会同时重置车间结转、删除结算记录，并让后续未锁账期间的自动承接和结算结果失效 → 必须重新走「车间结转 → 完整结算 → 勾稽 → 再锁账」。
  5. 开始下一个月：上期锁账后进入新期间（新期间不存在时先在后台新建：/admin/settlement/accountingperiod/add/）→ 导入资料 → 匹配 → 车间费用录入 → 车间结转 → 完整结算 （自动承接上期期末库存、在产品、未完工订单、合同余额）→ 勾稽 → 锁账。
  6. 如何进入下一个期间：回首页（期间列表），点那一期的「进入月结」按钮即可； 也可以直接打开 /periods/<期间id>/。 页面顶部显示的期间名与状态是当前所在期间，不是切换器。

HOW IT IS CALCULATED

取数口径与说明

  • 数据来源：期初采购暂估台账 ＋ 采购合同（签收数量）＋ 采购发票。不使用库存流水。
  • 到货：上传的合同＝货已收到；到货数量取「已签收数量」，没填才用合同数量；归属期间取合同「收货期间」， 没填用合同所属期间。归属晚于本期的合同本期不挂。
  • 到票（发票对照）：先按「合同号+物料」冲合同行；冲不上再按「供应商+物料」按期间先后冲 （先冲期初台账、再冲上月合同、最后本月合同）；发票期间早于到货归属期间的不冲。
  • 本月到货到票：借 {{ voucher.accounts.raw }} / 贷 {{ voucher.accounts.supplier }}；价差进 {{ voucher.accounts.difference }}。
  • 本月货到票未到-暂估入账：借 {{ voucher.accounts.raw }} / 贷 {{ voucher.accounts.accrued }}。
  • 前期暂估本月到票（回冲）：借 {{ voucher.accounts.accrued }}（合同价/台账价）/ 贷 {{ voucher.accounts.supplier }}（发票价）， 价差进 {{ voucher.accounts.difference }}；不再出现「借原材料＝贷原材料」同额对开。
  • 首期建账：最早一期把期初暂估台账全额做一张「借 {{ voucher.accounts.raw }} / 贷 {{ voucher.accounts.accrued }}」， 否则回冲历史台账会把暂估应付冲成借方。若旧系统已入过账，可去掉这块。
  • 金额口径：发票金额取上传文件的「不含税金额」（为空才用 数量×单价）；发票金额与 数量×单价 不一致的行， 会在「生成前检查」里提示，并进导出的「附件7-发票金额异常」。
  • 已批准忽略的合同行、发票行、期初台账行一律不计入。

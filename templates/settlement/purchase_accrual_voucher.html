HOW IT IS CALCULATED

取数口径与说明

  • 数据来源：库存出入库流水（采购入库）＋ 采购合同暂估价 ＋ 采购发票核销 ＋ 期初暂估台账。
  • ① 本月到货＋本月到票：借 {{ voucher.accounts.raw }} / 贷 {{ voucher.accounts.supplier }}—XX供应商； 同一入库单只到票一部分的，按数量拆开，已到票部分走①、未到票部分走②。
  • ② 本月到货＋月末未到票：借 {{ voucher.accounts.raw }} / 贷 {{ voucher.accounts.accrued }}。
  • ③ 前期暂估＋本月到票：借 {{ voucher.accounts.accrued }}（冲回原暂估）/ 贷 {{ voucher.accounts.supplier }}—XX供应商；发票与暂估价不同时，差额进 {{ voucher.accounts.difference }}。
  • 暂估单价来源：合同未税价优先，其次期初暂估台账单价 / 手工暂估价；都没有则记为「缺少暂估价格」， 该行金额按 0 计（会漏记，见生成前检查）。
  • 金额口径：入库金额 ＝ 入库数量 × 合同暂估不含税价；发票核销不改写库存入库金额， 所以价差只能在凭证层体现（本平台口径：差异进 {{ voucher.accounts.difference }}）。
  • 已批准忽略的流水与发票行一律不计入，与「月末采购暂估」「暂估回冲明细」页面口径一致。
  • 期初暂估台账（系统首期导入的历史未到票）不自动进本次凭证，避免与旧系统重复入账； 是否首期建账需要先确认。账龄见附件3 下方。
